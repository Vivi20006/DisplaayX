Honest limits

What it can’t do.

Better you read it here than find out mid-match.

Fullscreen

Use borderless

Borderless fullscreen works fully. In exclusive fullscreen the gamma path keeps working, but the saturation and vibrance layer does not.

AMD

Vibrance goes desktop-wide

Modern AMD drivers refuse ADL saturation, so vibrance and saturation run through the Windows Magnification API. That effect is desktop-wide and doesn’t show in captures — use the LUT export for streams.

Equalizer

Needs Equalizer APO

DisplayX installs it for you — file size and checksum shown first, one admin confirmation.

FAQ

Questions?

Is this a cheat or an anti-cheat risk?

No. DisplayX never touches a game process, reads no game memory and injects nothing. It only uses Windows display settings — the same APIs your driver’s control panel uses.

Can people see the colours in my stream?

Not by default — Windows applies the colours after the frame is composed, so OBS and Discord capture the original image. Export the .cube LUT and add it with OBS’s “Apply LUT” filter.

Does it work in fullscreen?

Borderless fullscreen works fully. In exclusive fullscreen only the gamma part works; the saturation and vibrance layer doesn’t. Use borderless.

What happens if it crashes?

Your original colours are saved at startup and written back on exit, logoff and even after a crash — a stuck colour cast can’t happen.

Does the equalizer need extra software?

Yes, Equalizer APO (free, open source). DisplayX detects it and offers to install it, showing the file size and SHA-256 before anything runs.

Do I need .NET?

No. The download is one self-contained file and uses the WebView2 runtime that ships with Windows 10 and 11.

Why do I need an account?

The download and the app are tied to a free account (email, Google or Discord). The app asks you to sign in with it on first start. DisplayX stays free for everyone.
