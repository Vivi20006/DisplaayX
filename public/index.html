Headset equalizer

Hear footsteps before you see them.

Ten bands from 31 Hz to 16 kHz, −12 to +12 dB, on the Windows playback path — so it works in every game and app.

  • Presets: Flat, Bass boost, Bass max, Gaming, Footsteps, Voice
  • Footsteps cuts the rumble and lifts 2–8 kHz
  • An automatic pre-amp cut keeps boosted sound from clipping
  • Profiles can carry the EQ setting, so colours and sound switch together

Needs Equalizer APO (free, open source). DisplayX detects it, offers to download and install it, and shows the file size and SHA-256 before running anything. Attaching it to a device needs one admin confirmation and briefly restarts Windows audio.

Honest limits

What DisplayX can’t do.

Better you read it here than find out in a match.

Exclusive fullscreen

Borderless fullscreen works fully. In exclusive fullscreen the gamma path keeps working, but the saturation and vibrance layer does not. Use borderless.

Vibrance on AMD

Modern AMD drivers refuse ADL saturation, so on AMD vibrance and saturation go through the Windows Magnification API. That effect is desktop-wide and doesn’t show in screen captures — use the LUT export for streams.

Equalizer needs APO

The equalizer runs on Equalizer APO. DisplayX installs it for you, with file size and checksum shown first, and needs one admin confirmation.

FAQ

Questions gamers actually ask.

Is this a cheat or an anti-cheat risk?

No. DisplayX never touches a game process, reads no game memory and injects nothing. It only uses Windows display settings — the same APIs your driver’s control panel uses.

Can people see the colours in my stream?

Not by default: Windows applies the colours after the frame is composed, so OBS and Discord capture the original image. Export the .cube LUT from DisplayX and add it with OBS’s “Apply LUT” filter — then viewers see what you see.

Does it work in fullscreen?

Borderless fullscreen works fully. In exclusive fullscreen only the gamma part works; the saturation and vibrance layer doesn’t. We recommend borderless.

What happens if it crashes?

Your original colours are saved at startup and written back on exit, logoff and even after a crash — a stuck colour cast can’t happen.

Does the equalizer need extra software?

Yes, Equalizer APO (free, open source). DisplayX detects it and offers to install it, showing the file size and SHA-256 checksum before anything runs.

Do I need .NET?

No. The download is one self-contained file. It uses the WebView2 runtime that already ships with Windows 10 and 11.

Why do I need an account?

The download and the app are tied to a free account — email, Google or Discord. The app asks you to sign in with the same account on first start. DisplayX stays free for everyone.
